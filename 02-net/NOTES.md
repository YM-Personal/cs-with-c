# 02-net — 학습 노트

C 소켓으로 "포트 열고 기다리는 서버"를 직접 만들며 네트워크의 원리를 손으로 익힌다.
디딤돌 3단계로 감각을 쌓은 뒤, **01-snake를 2인 네트워크 대전으로 확장**하는 게 캡스톤.

> 환경: **WSL(Ubuntu)** + gcc. (01-snake의 Windows/MSYS2와 다름 — 자세한 이유는 stage-0 상단.)

## 진행 현황

| Stage | 내용 | CS 개념 | 상태 |
|---|---|---|---|
| 0 | 에코 서버 (받은 걸 그대로 반환) | 소켓 5형제, 포트, TCP, 바이트순서, 블로킹 | ⬜ |
| 1 | 숫자 맞히기 (서버 정답 / 클라 추측) | 프로토콜 설계, 클라이언트도 직접 작성 | ⬜ |
| 2 | 틱택토 (턴제 2인 대전) | 서버가 게임상태 보유, 상태 전송, 순서 제어 | ⬜ |
| 3 (캡스톤) | 2인 네트워크 뱀게임 | 논블로킹 소켓 + 게임루프, 상태 직렬화 | ⬜ |

  - 지금 서버가 한 번에 한 명만 받는 이유를 루프 구조로?

## 처음 본 C 문법

> 단계마다 새로 만난 문법을 한 줄씩.

- **Stage 0**
  - `socket(AF_INET, SOCK_STREAM, 0)` — TCP 소켓 생성, fd 반환.
  - `struct sockaddr_in` — IP+포트를 담는 구조체 (`.sin_family/.sin_addr/.sin_port`).
  - `htons(port)` — 호스트→네트워크 바이트순서 변환.
  - `bind / listen / accept / recv / send / close` — 서버 소켓 일생.
  - `perror("...")` — 직전 시스템 콜 실패 사유 출력.
  - `setsockopt(..., SO_REUSEADDR, ...)` — 재시작 시 포트 재사용.

## 깨달은 CS 개념

> 단계마다 "아 이거구나" 한 것을 짧게. (직접 채워가기)

- **Stage 0** — _자기 말로 채울 것._
  - (예: accept가 "잠들어 기다리는" 그 지점 = 지난 대화의 "서버는 자다 깬다"의 실체)
